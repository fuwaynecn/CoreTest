# Family Math Trainer Phase 4 Task 1: AI 配置设计

- 日期：2026-08-26
- 状态：待用户审阅
- 依赖：已完成的 Phase 3；既有家庭数学训练系统设计文档第 15、16、18 节

## 1. 目标

为家长提供一个安全、可变更的 AI 服务配置入口。家长以后可以在设置中更换 OpenAI 或 DeepSeek 的 API 地址、模型名和 API Key，不需要修改代码；未配置 AI 时，训练、判分、排课和报告仍然正常工作。

Task 1 只交付配置管理，不交付调用限额、超时、供应商降级或 AI 生成能力；这些属于 Phase 4 Task 2 及以后。

## 2. 方案选择

采用单体应用内的“数据库配置 + 服务端加密”方案：

- SQLite 保存每个服务商一条配置记录。
- API Key 使用 AES-256-GCM 在服务端加密保存。
- 环境变量 `AI_CONFIG_ENCRYPTION_KEY` 是加密主密钥，不保存具体服务商 Key。
- 浏览器只能看到掩码和非敏感配置；完整 Key 永不返回客户端、日志或错误消息。
- 只有家长会话可以读取或修改配置。

不采用环境变量专属方案，因为它不能满足在家长设置中随时换 Key；不采用明文数据库，因为备份或磁盘泄露会直接暴露凭据。

## 3. 数据模型

新增 `ai_provider_configs` 表：

| 字段 | 约束与用途 |
| --- | --- |
| `provider` | 主键；`openai` 或 `deepseek` |
| `base_url` | 必填 HTTPS/HTTP URL，允许使用 OpenAI 兼容地址 |
| `model` | 必填、长度受限的模型标识 |
| `encrypted_api_key` | 可空；AES-256-GCM 密文，不存明文 |
| `enabled` | 是否允许后续 AI 适配层选用 |
| `created_at` / `updated_at` | 毫秒时间戳 |

Task 1 不加入限额、使用日志、默认/备用模型字段，避免提前耦合 Task 2。一个服务商只保留一条当前配置；换模型或 Key 是更新这条记录。

## 4. 服务端接口

新增家长专用路由 `/api/parent/ai-config`：

- `GET`：返回 OpenAI、DeepSeek 的非敏感配置及 `apiKeyMasked`（例如 `••••••abcd`）、是否已配置和更新时间；绝不返回密文。
- `POST`：创建或更新一个服务商配置。`apiKey` 只在新增或更换时提交；省略时保留已有 Key。使用 `clearApiKey: true` 明确清除 Key。
- 所有请求先校验家长身份，再校验严格的 Zod 输入；孩子会话返回 403，未登录返回 401。
- 主密钥缺失或格式不合规时，保存操作返回可理解的服务端配置错误；不影响其他核心功能。

输入限制：服务商为白名单值；地址必须是 URL；模型名和 Key 有长度上限；不接受未知字段。更新时同一服务商使用幂等 upsert。

## 5. 家长端交互

在现有家长页增加“AI 服务配置”区块，每个服务商显示：

- 启用开关。
- API 地址。
- 模型名称。
- 已配置 Key 的掩码状态。
- “更换 Key”输入框和“清除 Key”操作。
- 保存成功/失败提示。

页面首次加载只取掩码数据。输入框不会预填完整 Key；保存失败时不回显提交内容。孩子端不渲染该区块，也不能调用该路由。

## 6. 加密与隐私边界

- 使用 Node `node:crypto` 的 AES-256-GCM；每次加密随机生成 nonce，并保存版本、nonce、密文和认证标签。
- `AI_CONFIG_ENCRYPTION_KEY` 不写入数据库、前端构建产物或 Git；生产环境必须通过部署平台的 Secret 注入。
- 解密只发生在服务端 AI 适配层调用前；Task 1 的 GET、页面 props、日志和测试输出都不包含明文。
- Key 更换后旧密文被覆盖；清除操作将密文字段置空。
- 不发送孩子姓名、账号等非必要身份信息；Task 2 才定义请求内容和日志策略。

## 7. 迁移与兼容

- 通过 Drizzle 生成一次新增表迁移；不修改已有训练数据。
- 没有配置记录时，GET 返回两个“未配置”状态，核心应用继续使用预设提示和已审核讲解。
- 旧数据库启动时执行现有迁移流程即可；不要求用户先创建 Key。

## 8. 测试与验收

单元/集成测试至少覆盖：

1. 加密后密文不等于明文，正确主密钥可解密，错误主密钥和篡改密文会失败。
2. API Key 只返回掩码；GET、校验错误和异常响应均不泄露明文。
3. 未登录、孩子身份不能读写；家长可以创建、更新、停用和清除配置。
4. 省略 `apiKey` 会保留旧 Key；`clearApiKey` 会清空旧 Key。
5. 非法服务商、URL、模型名、未知字段和过长输入被拒绝。
6. 无任何 AI 配置时，现有核心测试和构建保持通过。

Task 1 的完成标准是：家长能在页面保存并修改 OpenAI/DeepSeek 的地址、模型和 Key，数据库不存明文，孩子无法接触配置，且不配置 AI 不影响既有训练流程。
