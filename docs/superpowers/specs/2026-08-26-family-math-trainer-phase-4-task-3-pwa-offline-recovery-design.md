# 家庭数学训练 Phase 4 Task 3：PWA、离线与中断恢复设计

## 1. 目标

让孩子主要使用的平板网页具备可安装的 PWA 体验，并在短暂断网、刷新或意外退出时保留当前作答，联网后可以安全恢复提交，不改变服务端判分、掌握度和积分的权威性。

## 2. 范围

本 Task 只覆盖：

- PWA manifest、Service Worker 注册和静态应用壳缓存。
- 浏览器在线/离线状态提示。
- 日常训练和诊断作答的本地草稿保存。
- 网络失败时的待同步提交队列，以及恢复联网后的重试。
- 页面刷新或关闭后恢复当前待答内容。

本 Task 不覆盖：

- 完全离线判分、离线排课或离线生成题目。
- 缓存个性化 API 响应、认证信息或服务端数据库。
- AI 额度、供应商切换、备份、云部署和运行监控。
- 新增第三方 PWA/IndexedDB 依赖。

## 3. 设计决策

### 3.1 PWA 资源

- `public/manifest.webmanifest` 提供中文名称、平板图标、`standalone` 显示模式和主题色。
- `public/sw.js` 只缓存同源静态资源和当前应用壳；不缓存 `/api/`、登录响应、家长数据或孩子作答响应。
- 客户端注册组件只在浏览器环境注册 Service Worker，并展示安装所需的基础状态，不强制弹出安装提示。

### 3.2 本地存储

使用原生 `localStorage`，原因是当前产品是单家庭、低并发、短文本草稿场景，足以覆盖需求且不引入依赖。

- 草稿按 `sessionItemId` 隔离，保存答案文本、审题卡字段和更新时间。
- 待同步队列按唯一 `clientSubmissionId` 保存提交地址、请求体和创建时间。
- 不保存 API Key、认证 Cookie、服务端响应或完整用户身份资料。
- 解析失败、空间不足或浏览器禁用存储时，继续在线使用，并显示无法暂存的明确提示。

### 3.3 提交与同步

- `AnswerForm` 和 `DiagnosisAnswerForm` 继续优先调用现有提交函数。
- 网络异常或无法确认的响应才进入待同步队列；400/401/403/404 等确定性错误仍直接提示孩子修改或重新登录。
- 恢复联网后按创建顺序逐条发送，成功的 2xx 请求从队列移除；确定性 4xx 移除并显示失败状态；其他错误保留并允许手动重试。
- 始终复用已有 `clientSubmissionId`，依靠服务端幂等保护避免重复积分、重复掌握度更新。
- 队列同步不伪造判分结果；页面在无法取得服务端结果时显示“已暂存，等待同步”，孩子可在同步后重新打开题目确认结果。

### 3.4 中断恢复

- 答案输入、审题卡和草稿变化时写入本地草稿。
- 页面加载时按当前 `sessionItemId` 恢复草稿。
- 训练页面刷新或关闭后，未完成题目保持可继续；已成功完成的题目仍由服务端状态决定。
- 会话结束并确认服务端完成后，清理该会话的草稿和已处理队列项。

## 4. 用户界面

- 全局轻量状态条：在线、离线、正在同步、同步失败。
- 提交失败但已暂存时，答案区域保留内容并显示“网络恢复后会自动提交”；提供“立即重试”。
- 不把“已暂存”显示成“已判分”或“训练已完成”。
- 保持现有 48px 最小触控目标和中文家长/孩子文案。

## 5. 数据流

```text
输入答案/草稿
  ├─ 本地草稿保存
  └─ 提交
       ├─ 服务端返回明确结果 → 展示结果并清理草稿
       ├─ 确定性错误 → 展示错误，不入队
       └─ 网络/未知响应 → 写入待同步队列

浏览器恢复联网
  └─ 按 clientSubmissionId 顺序同步
       ├─ 2xx → 删除队列项
       ├─ 4xx → 删除并显示需人工处理
       └─ 其他失败 → 保留并等待下一次重试
```

## 6. 安全与一致性

- Service Worker 不拦截或缓存 API 请求，避免跨账号或过期数据泄露。
- 本地队列只保存完成提交所需的最小答案载荷，不记录密钥或响应内容。
- 所有服务端判分、诊断进度、掌握度和奖励仍是唯一权威来源。
- 同一提交的幂等标识不可在重试时更换。

## 7. 验收与测试

至少覆盖：

1. manifest 可访问，Service Worker 注册且不缓存 API。
2. 在线状态变化会更新状态条。
3. 日常训练和诊断表单刷新后可恢复答案/审题卡草稿。
4. 网络失败会保存待同步请求，恢复联网后按顺序重试。
5. 重试复用相同 `clientSubmissionId`，不会生成第二个提交标识。
6. 确定性 4xx 不进入队列，未知网络错误不丢失内容。
7. 会话完成后清理草稿；未保存内容不会显示为已完成。
8. 不配置 AI 时现有核心流程、lint、类型检查、全量测试和构建继续通过。

## 8. 完成标准

孩子在平板上安装 PWA 后，即使短暂断网、刷新或关闭页面，当前答案和草稿也不会无提示丢失；网络恢复后系统能够安全重试，服务端仍负责最终判分和学习状态更新。
