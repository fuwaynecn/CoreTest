为 Phase 3 的题库扩充建立可执行基线：确认现有题型、能力域、难度和变式覆盖，识别优先缺口，并冻结 Task 2 的首批新增题量。Task 1 只做审计和规划，不新增题目、不修改排课规则。

审计对象：`web/src/content/phase2-catalog.ts`、`web/src/content/phase1-daily.ts` 及现有题目校验测试。

## 缺口判断

### P0：优先补齐

1. **数据与统计**：先补表格、条形图、折线图、平均数、数据比较、可能性之间的连续梯度；每个技能至少形成“基础—应用—迁移”三档。
2. **几何与空间**：补 1 级入门题，以及长度/面积/体积单位转换、组合图形和空间观察的多题型变式。
3. **整数与基础算力**：补整数口算、四则混合、估算和逆运算检查，覆盖 1–4 级而不是集中在 2 级。

### P1：增强迁移

1. **方程**：保持 L1–L6 梯度，补 L1/L2 的过渡题和 L5/L6 的建模、检验题，避免只重复 `equation-direct`、`equation-step`、`equation-model-check` 三种结构。
2. **应用建模**：补 1 级价格/行程/比与分配入门，再增加百分数、多步应用和反向建模的 4 级题。
3. **思维习惯**：围绕“问题问什么、哪些条件有用、单位、估算、检查”增加跨学科情境，直接服务女儿目前的审题粗心问题。

## Task 2 输入约束

- 每道题必须拥有唯一 ID、能力域、skill、难度、结构标签、答案规范、解析、三阶提示和错误目标。
- 题目必须通过现有 catalog/template 校验；答案、单位和变量变式必须可确定验证。
- 新增 regional/transition 题应标注适用情境，不绑定某一省份教材版本；可吸收湖北、浙江等地常见题型的能力要求，但不复制受版权保护的原题。
- 先补 P0，再补 P1；同一结构标签至少提供 2 个可辨识变式，避免继续产生大量单例结构。
- 保持 `original / owned` 或明确可审计的来源与许可，不接入 AI 生成未经审核的题目。

## 验收标准

- 审计数字可由当前 catalog 导出脚本复现。
- Task 2 的 48 道新增题有能力域、难度、结构和验收优先级。
- 新题加入后，六个能力域都至少有基础、核心、迁移题；数据与几何不再是明显薄弱域。
- 现有 75 道题的答案校验、题目 ID 和 Phase 2 排课行为不回归。

## 边界

Task 1 完成后暂停。积分、徽章、视觉精修和题目实现属于后续 Phase 3 Task 2 及以后；AI 接入、PWA、备份和云部署属于 Phase 4。
